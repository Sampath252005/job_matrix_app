Step 4: Recruiter APIs

Create these APIs first:

POST   /api/assessments
GET    /api/assessments/job/:jobId
GET    /api/assessments/:assessmentId
PUT    /api/assessments/:assessmentId
DELETE /api/assessments/:assessmentId

Purpose:

Recruiter creates aptitude test for a job
Recruiter views test
Recruiter updates test
Recruiter deletes test
Step 5: Question APIs
POST   /api/assessments/:assessmentId/questions
GET    /api/assessments/:assessmentId/questions
PUT    /api/questions/:questionId
DELETE /api/questions/:questionId

Important: only recruiter should see correct_answer.

Step 6: Candidate APIs
GET  /api/jobs/:jobId/assessment
POST /api/assessments/:assessmentId/start
POST /api/attempts/:attemptId/answer
POST /api/attempts/:attemptId/submit
GET  /api/attempts/:attemptId/result

Important: candidate should not receive correct_answer.

Step 7: Backend scoring logic

When candidate submits:

1. Get all answers of attempt
2. Compare selected_answer with correct_answer
3. Calculate score
4. Update attempt status
5. Store score

Example:

score >= passing_score → passed
score < passing_score  → failed
